# Data Cleaning and Reporting Automation

## Project Overview
This project automates data cleaning and reporting using Python.

## Objectives
- Identify and handle missing values.
- Remove duplicate records.
- Clean inconsistent text data.
- Generate a cleaned CSV dataset.
- Create a visual sales report.
- Calculate useful sales statistics.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab
- GitHub

## Project Files
- data_cleaning.py: Main Python script.
- sales_data.csv: Original sales dataset.
- cleaned_data.csv: Cleaned dataset.
- report.png: Sales visualization.

## Features
1. Missing value detection and handling.
2. Duplicate record removal.
3. Text standardization.
4. Automated CSV generation.
5. Sales visualization.
6. Sales summary statistics.

## How to Run
Install the required libraries:

pip install pandas matplotlib

Run the Python script:

python data_cleaning.py

## Expected Outcome
A cleaned sales dataset, a visual sales report, and summary statistics.

## Conclusion
This project demonstrates how Python can improve data quality and automate reporting tasks.
